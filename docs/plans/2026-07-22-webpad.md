# WebPad - 虚拟手柄模拟器 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个 Rust 桌面程序，在电脑上运行后，手机浏览器访问即可作为虚拟手柄使用，通过 WebSocket 实时传输手柄输入到电脑端，由 ViGEm 模拟为 Xbox 360 手柄。

**Architecture:** 分层架构 —— `protocol` 层定义 WebSocket 消息格式（客户端 <-> 服务端）；`gamepad` 层封装 vigem-client 的同步 API 为异步接口，内部用 `spawn_blocking` 桥接；`auth` 层实现基于预共享密钥（PSK）的 token 认证；`upnp` 层用 portmapper 自动端口映射；`web` 层用 axum 组装 HTTP + WebSocket 服务，提供手机端页面。传输加密依赖 TLS（wss://），axum-server + rustls 实现。

**Tech Stack:** Rust / tokio 1.53 / axum 0.8 (ws feature) / vigem-client 0.1.4 / portmapper 0.19.1 / axum-server 0.7 (tls-rustls) / rustls / serde + serde_json

**关键设计决策：**

1. **vigem-client 是同步的**：所有 vigem 操作通过 `tokio::task::spawn_blocking` 在阻塞线程池执行。`Client` 用 `Arc` 共享，避免 `transmute` UB。
2. **`Arc<Mutex<Xbox360Wired<Arc<Client>>>>`**：`Arc<Client>` 可安全 clone 到 spawn_blocking。`std::sync::Mutex` 保护 `update()` 的 `&mut self`。
3. **PSK 认证**：启动时生成密码显示在终端。WebSocket 升级前通过 query param `?token=xxx` 验证 token。无密码模式跳过验证。
4. **WebSocket 内二次认证检查**：handle_socket 维护 `authenticated` 布尔标志，未认证时拒绝 `GamepadState` 消息。
5. **协议层独立于手柄层**：`protocol.rs` 定义纯数据结构，`gamepad/types.rs` 将协议消息转换为 vigem 的 `XGamepad`。
6. **UPnP 长期持有**：`portmapper::Client` 在 main.rs 中与服务器同生命周期，后台 Service 自动续期映射。
7. **TLS 可选**：默认支持 ws:// 和 wss://，未配置证书时仅 ws。
8. **震动反馈**：vigem-client 0.1.4 的 Xbox360Wired 无公开震动接收 API，Rumble 消息保留在协议中但当前为空实现（TODO）。
9. **心跳检测**：服务端使用 `tokio::select!` 在消息循环中同时监听 WebSocket 消息和心跳超时。客户端（手机浏览器 JS）每 5 秒发送一次 `Heartbeat`，服务端回复 `Pong`。若连续 30 秒未收到任何消息（含心跳），判定连接失活，自动销毁控制器并清理 session，防止僵尸连接。

```rust
use rand::Rng;
use sha2::{Sha256, Digest};
use std::fmt;
use std::net::SocketAddr;

/// 应用配置
pub struct Config {
    /// HTTP/WS 监听端口
    pub port: u16,
    /// 密码的 SHA-256 哈希（空字符串表示无密码）
    pub password_hash: String,
    /// TLS 证书文件路径（None 表示不启用 TLS）
    pub cert_path: Option<String>,
    /// TLS 私钥文件路径
    pub key_path: Option<String>,
    /// 是否启用 UPnP 端口映射
    pub enable_upnp: bool,
    /// 心跳超时秒数（超过此时间未收到任何消息判定连接失活）
    pub heartbeat_timeout_secs: u64,
}

impl Default for Config {
    fn default() -> Self {
        Self {
            port: 8080,
            password_hash: String::new(),
            cert_path: None,
            key_path: None,
            enable_upnp: true,
            heartbeat_timeout_secs: 30,
        }
    }
}

impl fmt::Display for Config {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        write!(
            f,
            "WebPad Config:\n  Port: {}\n  Auth: {}\n  UPnP: {}\n  TLS: {}\n  Heartbeat: {}s",
            self.port,
            if self.password_hash.is_empty() { "disabled" } else { "enabled" },
            self.enable_upnp,
            self.cert_path.as_deref().unwrap_or("disabled"),
            self.heartbeat_timeout_secs,
        )
    }
}

impl Config {
    /// 获取监听地址
    pub fn listen_addr(&self) -> SocketAddr {
        SocketAddr::from(([0, 0, 0, 0], self.port))
    }

    /// 设置密码
    pub fn set_password(&mut self, password: &str) {
        self.password_hash = hash_password(password);
    }

    /// 验证密码
    pub fn verify_password(&self, password: &str) -> bool {
        if self.password_hash.is_empty() {
            return true;
        }
        hash_password(password) == self.password_hash
    }

    /// 心跳超时的 Duration
    pub fn heartbeat_timeout(&self) -> std::time::Duration {
        std::time::Duration::from_secs(self.heartbeat_timeout_secs)
    }
}

/// 生成随机密码
pub fn generate_password(length: usize) -> String {
    const CHARSET: &[u8] = b"ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnpqrstuvwxyz23456789";
    let mut rng = rand::thread_rng();
    (0..length)
        .map(|_| {
            let idx = rng.gen_range(0..CHARSET.len());
            CHARSET[idx] as char
        })
        .collect()
}

/// 对密码进行 SHA-256 哈希
pub fn hash_password(password: &str) -> String {
    let mut hasher = Sha256::new();
    hasher.update(password.as_bytes());
    hex::encode(hasher.finalize())
}
```

use rand::Rng;
use sha2::{Sha256, Digest};
use std::collections::HashSet;
use std::sync::{Arc, Mutex};

/// 认证管理器
#[derive(Clone)]
pub struct AuthManager {
    /// 密码哈希（空字符串表示无密码模式）
    password_hash: String,
    /// 活跃的 session token 集合（std::sync::Mutex，锁持有极短）
    sessions: Arc<Mutex<HashSet<String>>>,
}

impl AuthManager {
    /// 创建认证管理器（需要密码）
    pub fn new(password_hash: String) -> Self {
        Self {
            password_hash,
            sessions: Arc::new(Mutex::new(HashSet::new())),
        }
    }

    /// 创建无密码认证管理器
    pub fn no_password() -> Self {
        Self {
            password_hash: String::new(),
            sessions: Arc::new(Mutex::new(HashSet::new())),
        }
    }

    /// 验证密码
    pub fn verify_password(&self, password: &str) -> bool {
        if self.password_hash.is_empty() {
            return true;
        }
        hash_input(password) == self.password_hash
    }

    /// 创建新的 session token
    pub async fn create_session(&self) -> String {
        let token = generate_token();
        self.sessions.lock().unwrap().insert(token.clone());
        token
    }

    /// 验证 token 是否有效
    pub async fn validate_token(&self, token: &str) -> bool {
        if token.is_empty() {
            return false;
        }
        self.sessions.lock().unwrap().contains(token)
    }

    /// 移除 session
    pub async fn remove_session(&self, token: &str) {
        self.sessions.lock().unwrap().remove(token);
    }

    /// 当前活跃 session 数量
    pub fn session_count(&self) -> usize {
        self.sessions.lock().unwrap().len()
    }

    /// 是否启用了密码（非无密码模式）
    pub fn is_password_enabled(&self) -> bool {
        !self.password_hash.is_empty()
    }
}

fn generate_token() -> String {
    let mut rng = rand::thread_rng();
    let bytes: Vec<u8> = (0..32).map(|_| rng.gen()).collect();
    hex::encode(bytes)
}

fn hash_input(input: &str) -> String {
    let mut hasher = Sha256::new();
    hasher.update(input.as_bytes());
    hex::encode(hasher.finalize())
}

use super::types::GamepadState;
use std::collections::HashMap;
use std::sync::atomic::{AtomicUsize, Ordering};
use std::sync::{Arc, Mutex};
use tracing::{info, warn};

#[cfg(windows)]
use vigem_client::{Client, Xbox360Wired, XGamepad};

/// 手柄控制器 ID 类型
pub type ControllerId = u32;

/// 虚拟手柄管理器
pub struct GamepadManager {
    #[cfg(windows)]
    controllers: Arc<Mutex<HashMap<ControllerId, Arc<Mutex<Xbox360Wired<Arc<Client>>>>>>>,
    #[cfg(windows)]
    next_id: AtomicUsize,
    #[cfg(windows)]
    client: Option<Arc<Client>>,
    #[cfg(windows)]
    controller_count: AtomicUsize,
    #[cfg(not(windows))]
    _private: (),
}

impl GamepadManager {
    /// 创建新的手柄管理器
    pub async fn new() -> Self {
        #[cfg(windows)]
        {
            let client = match Client::connect() {
                Ok(c) => {
                    info!("Connected to ViGEmBus driver");
                    Some(Arc::new(c))
                }
                Err(e) => {
                    warn!("ViGEmBus not available: {}. Virtual gamepad will not work.", e);
                    None
                }
            };
            Self {
                controllers: Arc::new(Mutex::new(HashMap::new())),
                next_id: AtomicUsize::new(1),
                client,
                controller_count: AtomicUsize::new(0),
            }
        }
        #[cfg(not(windows))]
        {
            warn!("Gamepad emulation is only supported on Windows");
            Self { _private: () }
        }
    }

    /// 创建新的虚拟控制器，返回控制器 ID
    pub async fn create_controller(&self) -> Result<ControllerId, String> {
        #[cfg(windows)]
        {
            let client = self.client.as_ref().ok_or("ViGEmBus not available")?;
            let client = Arc::clone(client);

            let target = tokio::task::spawn_blocking(move || {
                let mut target = Xbox360Wired::new(
                    client,
                    vigem_client::TargetId::XBOX360_WIRED,
                );
                target.plugin().map_err(|e| format!("Plugin failed: {}", e))?;
                target.wait_ready().map_err(|e| format!("Wait ready failed: {}", e))?;
                Ok::<_, String>(target)
            })
            .await
            .map_err(|e| format!("Task join error: {}", e))??;

            let id = self.next_id.fetch_add(1, Ordering::SeqCst) as u32;
            self.controllers.lock().unwrap().insert(id, Arc::new(Mutex::new(target)));
            self.controller_count.fetch_add(1, Ordering::SeqCst);
            info!("Created virtual controller #{}", id);
            Ok(id)
        }
        #[cfg(not(windows))]
        {
            Err("Gamepad emulation not supported on this platform".to_string())
        }
    }

    /// 更新控制器状态
    pub async fn update_state(&self, id: ControllerId, state: &GamepadState) -> Result<(), String> {
        #[cfg(windows)]
        {
            let target = {
                let guard = self.controllers.lock().unwrap();
                guard.get(&id).map(Arc::clone).ok_or(format!("Controller #{} not found", id))?
            };

            let gamepad = XGamepad {
                buttons: vigem_client::XButtons { raw: state.buttons },
                left_trigger: state.left_trigger,
                right_trigger: state.right_trigger,
                thumb_lx: state.thumb_lx,
                thumb_ly: state.thumb_ly,
                thumb_rx: state.thumb_rx,
                thumb_ry: state.thumb_ry,
            };

            tokio::task::spawn_blocking(move || {
                let mut t = target.lock().unwrap();
                t.update(&gamepad).map_err(|e| format!("Update failed: {}", e))
            })
            .await
            .map_err(|e| format!("Task join error: {}", e))?
        }
        #[cfg(not(windows))]
        {
            Err("Gamepad emulation not supported on this platform".to_string())
        }
    }

    /// 销毁控制器
    pub async fn destroy_controller(&self, id: ControllerId) {
        #[cfg(windows)]
        {
            let target = {
                let mut guard = self.controllers.lock().unwrap();
                guard.remove(&id)
            };

            if let Some(target) = target {
                self.controller_count.fetch_sub(1, Ordering::SeqCst);
                tokio::task::spawn_blocking(move || {
                    let mut t = target.lock().unwrap();
                    let _ = t.unplug();
                })
                .await
                .ok();
                info!("Destroyed virtual controller #{}", id);
            }
        }
    }

    /// 当前活跃控制器数量
    pub fn controller_count(&self) -> usize {
        #[cfg(windows)]
        {
            self.controller_count.load(Ordering::SeqCst)
        }
        #[cfg(not(windows))]
        {
            0
        }
    }

    /// 关闭管理器，清理所有控制器
    pub async fn shutdown(&self) {
        #[cfg(windows)]
        {
            let controllers: Vec<_> = {
                let mut guard = self.controllers.lock().unwrap();
                std::mem::take(&mut *guard)
            };

            for (id, target) in controllers {
                tokio::task::spawn_blocking(move || {
                    let mut t = target.lock().unwrap();
                    let _ = t.unplug();
                })
                .await
                .ok();
                info!("Shutdown controller #{}", id);
            }

            self.controller_count.store(0, Ordering::SeqCst);
        }
    }
}

use portmapper::{Client as PmClient, Config, Protocol};
use std::num::NonZeroU16;
use tracing::{info, warn};

/// 端口映射结果
#[derive(Debug)]
pub enum PortMappingResult {
    /// 映射成功
    Success {
        external_addr: String,
        protocol: String,
    },
    /// 映射不可用（非致命错误）
    NotAvailable {
        reason: String,
    },
    /// UPnP 被禁用
    Disabled,
}

impl PortMappingResult {
    pub fn display(&self) -> String {
        match self {
            Self::Success { external_addr, protocol } => {
                format!("Port mapping OK ({}): {}", protocol, external_addr)
            }
            Self::NotAvailable { reason } => {
                format!("Port mapping not available: {}", reason)
            }
            Self::Disabled => "UPnP disabled by config".to_string(),
        }
    }
}

/// 创建 portmapper Client 并启动映射
/// 
/// 返回的 Client 必须由调用方持有，后台 Service 会自动续期映射。
/// 当 Client 被 drop 时，映射自动清理。
pub async fn start_port_mapping(
    local_port: u16,
) -> Result<(PmClient, PortMappingResult), PortMappingResult> {
    let config = Config {
        enable_upnp: true,
        enable_pcp: true,
        enable_nat_pmp: true,
        protocol: Protocol::Tcp,
    };

    let client = PmClient::new(config);

    // 探测可用协议
    let probe_result = client.probe().await;
    let protocol_name = match &probe_result {
        Ok(Ok(output)) => {
            if output.upnp {
                Some("UPnP")
            } else if output.pcp {
                Some("PCP")
            } else if output.nat_pmp {
                Some("NAT-PMP")
            } else {
                return Err(PortMappingResult::NotAvailable {
                    reason: "No port mapping protocol available".to_string(),
                });
            }
        }
        Ok(Err(e)) => {
            return Err(PortMappingResult::NotAvailable {
                reason: format!("Probe failed: {}", e),
            });
        }
        Err(_) => {
            return Err(PortMappingResult::NotAvailable {
                reason: "Probe cancelled".to_string(),
            });
        }
    };

    let protocol_name = protocol_name.unwrap();

    // 设置本地端口（Service 会自动维持映射）
    if let Some(port) = NonZeroU16::new(local_port) {
        client.update_local_port(port);
    } else {
        return Err(PortMappingResult::NotAvailable {
            reason: "Invalid port number".to_string(),
        });
    }

    // 等待首次映射结果
    let mut watcher = client.watch_external_address();
    if watcher.changed().await.is_err() {
        return Err(PortMappingResult::NotAvailable {
            reason: "Mapping watch cancelled".to_string(),
        });
    }

    match *watcher.borrow() {
        Some(addr) => {
            info!("Port mapping successful: {} -> {}", local_port, addr);
            let result = PortMappingResult::Success {
                external_addr: addr.to_string(),
                protocol: protocol_name.to_string(),
            };
            Ok((client, result))
        }
        None => Err(PortMappingResult::NotAvailable {
            reason: "Mapping failed (no external address)".to_string(),
        }),
    }
}

use serde::Deserialize;
use std::sync::Arc;
use crate::auth::AuthManager;
use crate::gamepad::GamepadManager;
use crate::protocol::{ClientMessage, ServerMessage};

/// WebSocket 连接查询参数
#[derive(Deserialize)]
pub struct WsQuery {
    token: Option<String>,
}

/// 首页处理器 - 返回虚拟手柄 HTML 页面
pub async fn index() -> Html<&'static str> {

/// WebSocket 连接处理器
/// 
/// 升级前检查 token（有密码模式下）。无密码模式跳过检查。
pub async fn ws_handler(
    ws: WebSocketUpgrade,
    Query(query): Query<WsQuery>,
    State((auth, gamepad, heartbeat_timeout)): State<(AuthManager, Arc<GamepadManager>, std::time::Duration)>,
) -> Response {
    // 有密码模式下必须提供有效 token
    if auth.is_password_enabled() {
        let token = query.token.as_deref().unwrap_or("");
        if !auth.validate_token(token).await {
            return (StatusCode::UNAUTHORIZED, "Invalid or missing token").into_response();
        }
    }

    ws.on_upgrade(move |socket| handle_socket(socket, auth, gamepad, heartbeat_timeout))
}

/// 处理已建立的 WebSocket 连接
/// 
/// 使用 tokio::select! 同时监听 WebSocket 消息和心跳超时。
/// 若在 heartbeat_timeout 内未收到任何消息（含心跳），自动断开并清理资源。
async fn handle_socket(
    mut socket: WebSocket,
    auth: AuthManager,
    gamepad: Arc<GamepadManager>,
    heartbeat_timeout: std::time::Duration,
) {
    let authenticated = Arc::new(tokio::sync::Mutex::new(!auth.is_password_enabled()));
    let session_token: Arc<tokio::sync::Mutex<Option<String>>> = Arc::new(tokio::sync::Mutex::new(None));
    let controller_id: Arc<tokio::sync::Mutex<Option<u32>>> = Arc::new(tokio::sync::Mutex::new(None));

    // 无密码模式下直接创建控制器
    if *authenticated.lock().await {
        match gamepad.create_controller().await {
            Ok(id) => {
                *controller_id.lock().await = Some(id);
            }
            Err(e) => {
                let _ = send_message(&mut socket, &ServerMessage::AuthFailure {
                    reason: format!("Controller creation failed: {}", e),
                }).await;
                return;
            }
        }
    }

    // 连接建立，发送欢迎消息
    let _ = send_message(&mut socket, &ServerMessage::Connected {
        controller_name: "WebPad Virtual Controller".to_string(),
    }).await;

    loop {
        let timeout = tokio::time::sleep(heartbeat_timeout);
        tokio::pin!(timeout);

        tokio::select! {
            msg = socket.recv() => {
                let msg = match msg {
                    Some(Ok(msg)) => msg,
                    // 连接关闭或出错
                     _ => break,
                 };
 
                 if let axum::extract::ws::Message::Text(text) = msg {
                    match serde_json::from_str::<ClientMessage>(&text) {
                        Ok(client_msg) => {
                            let should_continue = handle_client_message(
                                &mut socket, &auth, &gamepad,
                                &authenticated, &session_token, &controller_id,
                                client_msg,
                            ).await;
                            if !should_continue {
                                break;
                            }
                        }
                        Err(e) => {
                            tracing::debug!("Failed to parse message: {}", e);
                        }
                    }
                }
            }
            _ = timeout => {
                // 心跳超时，自动断开
                tracing::warn!(
                    "Heartbeat timeout ({}s), disconnecting client",
                    heartbeat_timeout.as_secs(),
                );
                break;
            }
        }
    }

    // 清理：销毁控制器 + 移除 session
    let id = *controller_id.lock().await;
    if let Some(id) = id {
        gamepad.destroy_controller(id).await;
    }
    let token = session_token.lock().await.take();
    if let Some(token) = token {
        auth.remove_session(&token).await;
    }
    tracing::info!("WebSocket connection cleaned up");
}

async fn handle_client_message(
    socket: &mut WebSocket,
    auth: &AuthManager,
    gamepad: &Arc<GamepadManager>,
    authenticated: &Arc<tokio::sync::Mutex<bool>>,
    session_token: &Arc<tokio::sync::Mutex<Option<String>>>,
    controller_id: &Arc<tokio::sync::Mutex<Option<u32>>>,
    msg: ClientMessage,
) -> bool {
    match msg {
        ClientMessage::AuthRequest { password } => {
            if auth.verify_password(&password) {
                let token = auth.create_session().await;
                *session_token.lock().await = Some(token.clone());
                *authenticated.lock().await = true;
                let _ = send_message(socket, &ServerMessage::AuthSuccess { token }).await;

                // 认证成功后创建控制器
                let mut cid = controller_id.lock().await;
                if cid.is_none() {
                    match gamepad.create_controller().await {
                        Ok(id) => {
                            *cid = Some(id);
                            tracing::info!("Created controller #{} after auth", id);
                        }
                        Err(e) => {
                            let _ = send_message(socket, &ServerMessage::AuthFailure {
                                reason: format!("Controller creation failed: {}", e),
                            }).await;
                        }
                    }
                }
            } else {
                let _ = send_message(socket, &ServerMessage::AuthFailure {
                    reason: "Invalid password".to_string(),
                }).await;
            }
            true
        }
        ClientMessage::GamepadState { .. } => {
            if !*authenticated.lock().await {
                let _ = send_message(socket, &ServerMessage::AuthFailure {
                    reason: "Not authenticated".to_string(),
                }).await;
                return true;
            }
            let id = *controller_id.lock().await;
            if let Some(id) = id {
                if let Some(state) = crate::gamepad::types::GamepadState::from_client_message(&msg) {
                    if let Err(e) = gamepad.update_state(id, &state).await {
                        tracing::warn!("Failed to update gamepad state: {}", e);
                    }
                }
            }
            true
        }
        ClientMessage::Heartbeat => {
            let _ = send_message(socket, &ServerMessage::Pong).await;
            true
        }
        ClientMessage::Disconnect { reason } => {
            tracing::info!("Client disconnecting: {}", reason);
            false
        }
    }
}

async fn send_message(socket: &mut WebSocket, msg: &ServerMessage) -> Result<(), ()> {
    let json = serde_json::to_string(msg).map_err(|_| ())?;
    socket.send(axum::extract::ws::Message::Text(json.into())).await.map_err(|_| ())
}

## 修正总结

| # | 问题 | 修正方案 |
|---|---|---|
| 1 | `block_in_place` + `block_on` 破坏调度 | `AuthManager` 全部 async API，内部用 `std::sync::Mutex` |
| 2 | `transmute` UB | `Client` 改为 `Arc<Client>`，clone 到 `spawn_blocking` |
| 3 | WebSocket 内无认证状态检查 | handle_socket 维护 `authenticated` 标志，未认证拒绝 `GamepadState` |
| 4 | ws_handler 无升级前认证 | 检查 `?token=` query param，无效返回 401 |
| 5 | GamepadManager 无法被 handler 访问 | `AppState = (AuthManager, Arc<GamepadManager>)` 传给 router |
| 6 | Rumble 接口缺失 | vigem-client 0.1.4 无公开震动 API，协议保留，空实现 |
| 7 | portmapper Client 一次 drop | `start_port_mapping` 返回 Client，main.rs 持有生命周期 |
| 8 | 测试绑定真实硬件 | 标记 `#[ignore = "requires ViGEmBus driver"]` |
| 9 | `controller_count` try_read 竞争 | 改用 `AtomicUsize` 跟踪 |
